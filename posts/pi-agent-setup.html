在终端里用上 Pi Agent

W.杨椀程·2026.11.02·阅读约 3 分钟

Pi 是一个运行在终端里的 AI Agent。这篇记录在 Mac 上完成安装、验证启动，以及连接模型的基本路径。

用官方方式安装

这次采用 Pi 官网提供的 npm 安装方式。安装前先确认 Node.js 和 npm 可用，再安装官方软件包。具体版本要求和最新命令，以 官方快速入门 ↗ 为准。

npm install -g --ignore-scripts @earendil-works/pi-coding-agent

如果使用用户目录作为 npm 安装前缀，要确保对应的 bin 目录已经加入终端的 PATH，这样才可以直接运行命令。

验证可以启动

先查看版本，再进入希望处理的项目目录并启动 Pi：

pi --version
cd /path/to/your/project
pi

本次安装验证时，Pi 版本为 1.4.0，交互界面正常启动。这个版本号是本次记录的环境信息，不代表始终是最新版本。

连接模型，才开始真正工作

Agent 程序与模型服务是两个环节。Pi 可以正常启动，并不意味着已经有可用的模型。在 Pi 中输入：

/login

按提示选择模型服务并完成授权，之后可以通过 /model 选择已连接的模型。不同服务的访问条件和费用，需要以所选服务的规则为准。

一个值得保留的检查顺序

命令是否能找到 → 界面是否正常启动 → 模型是否连接成功。把这些步骤分开，排查起来会更清楚。

参考：Pi 官网 ↗ · Quickstart ↗
