为什么我的 Agent 只有三个 Skill？

W.杨椀程·2026.11.02·阅读约 4 分钟

安装好 Pi 后，技能菜单里只有三个 Skill，别人却有几十个。这个差异，先要从技能在哪里、如何被加载看起。

先看目录，而不是数量

这次排查发现，Pi 识别到的三个有效技能来自电脑上已有的共享技能目录：浏览器操作、GIS 项目文档和课堂笔记整理。

Pi 支持从 ~/.agents/skills/ 等位置发现技能，也支持配置额外的技能路径。因此，同样安装 Pi，不同电脑上显示的技能数量可能完全不同。

Skill 提供的是任务流程

一个 Skill 通常以 SKILL.md 描述适用任务和执行步骤，也可以附带脚本、参考资料和资源文件。它帮助 Agent 在特定任务中采用更合适的方法。

技能数目并不是模型能力的评分。多一个技能，可能只是多了一套专门的文档工作流；少一个技能，也不意味着 Agent 就无法完成相关任务。

能发现，不等于能执行

有些技能依赖特定软件、插件、连接器或命令行工具。即使把技能目录复制过来，如果缺少底层接口，它也未必能正常工作。

补充技能时，需要同时检查：任务是否需要它、内容是否适用、依赖是否已安装，以及工具接口是否可用。

从一个实际需求开始

与其先追求一个很长的技能列表，不如围绕正在做的任务，安装一个、验证一个，再把有效的流程留下来。

在 Pi 中查看与使用

在输入框键入 /skill: 可以查看已发现的技能。修改技能文件后，可以用 /reload 重新加载资源。具体的发现规则和配置方式见 Pi 官方 Skills 文档 ↗。

写在最后
