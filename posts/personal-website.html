从一个想法，到一个可以访问的个人主页

W.杨椀程·2026.11.02·阅读约 3 分钟

一个个人主页，可以从很小的地方开始：说清楚自己是谁，留下一些真实的实践，让别人能通过一个链接找到你。

先让网站真正上线

这个网站采用 HTML、CSS 和 JavaScript 实现，通过 GitHub 仓库维护源码，再由 GitHub Pages 发布。它的公开地址是 wanchenghhh.github.io。

最初先完成桌面版页面，包含自我介绍、作品展示与阅读入口。之后将代码推送到与账号对应的 wanchenghhh.github.io 仓库，启用 Pages，从 main 分支的根目录发布。

界面需要服务内容

页面经历了从浅色作品集到深色山景首页的调整。这一次，主页转向以文字为中心的博客结构：用清楚的栏目、文章摘要和侧栏介绍，让访客更快找到想读的内容。

视觉方向可以变化，维护方式保持简单：在本地修改页面，提交到 Git，再推送到 GitHub，等待 Pages 自动发布。

这个空间接下来会记录什么？

AI 工具的实际使用、产品问题的思考，以及把一个想法做成可用东西的过程。先把真实发生的事情写下来，再慢慢长出自己的内容。

保持一个容易维护的起点

当前网站是静态站点，不需要数据库，也不包含账号注册或评论系统。优先保留必要的阅读与检索功能，让更新内容的成本尽可能低。

完整源码可以在 GitHub 仓库 ↗ 查看。
